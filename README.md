# RefBoard — 케이스 스터디 & 레퍼런스 정리 프로그램

매번 케이스와 레퍼런스를 새로 찾고 PPT에 붙이는 일을 줄이기 위한 도구입니다.

1. **모으기**: 핀터레스트 핀·보드, 웹페이지, 이미지 링크를 붙여넣고 **키워드(태그)**와 함께 저장합니다. 이미지는 따로 저장하지 않고 원본 링크로 연결합니다.
2. **찾기**: 키워드를 넣으면 관련도 순으로 **자동 정렬**하고 태그별로 묶어서 보여줍니다.
3. **문서 만들기**: 키워드 하나로 **태그·케이스별 그룹 → 페이지 → 레이아웃**까지 자동으로 구성합니다. 그리드(N단) 배치와 이미지 비율에 맞춘 자유 배치 중에서 고를 수 있습니다.
4. **다듬기**: AI(Claude)가 페이지마다 타이틀·태그라인·설명·캡션을 제안합니다. 폰트·크기·자간·행간을 세밀하게 조정할 수 있고, 프레젠테이션 도구처럼 요소를 옮기고 정렬할 수 있습니다.
5. **출력**: PDF(인쇄), PowerPoint, 단일 HTML 파일로 내보내거나 웹 뷰어·발표 모드로 바로 볼 수 있습니다.

기본 페이지 양식은 보고용 케이스 스터디 예시를 그대로 재현합니다.

- **케이스 페이지**: 타이틀 | 리그·팀 서브타이틀 | 강조 라인 + 설명, 로고 패널, 이미지 모자이크
- **레퍼런스(아이데이션) 페이지**: 타이틀 | 서브타이틀 | 설명, "Reference" 라벨, 이미지 배치
- **하단 양식**: 왼쪽 조직명(`SHINSEGAE BRAND OFFICE`), 오른쪽 문서명과 페이지 번호

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
cp .env.example .env       # (선택) ANTHROPIC_API_KEY 입력
npm run dev                # → http://127.0.0.1:5178
```

처음 열면 **"샘플 데이터로 체험하기"** 버튼으로 예시 케이스(Allianz Arena)와 조형물 레퍼런스를 불러와 바로 써볼 수 있습니다. 샘플 이미지는 자리표시용 그림입니다.

배포용 실행:

```bash
npm run build
npm start                  # NODE_ENV=production, dist/ 를 같은 서버에서 제공
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 (API + Vite, 한 포트) |
| `npm run build` / `npm start` | 프로덕션 빌드 / 실행 |
| `npm test` | 레이아웃 엔진·검색·그룹핑·스크래퍼 단위 테스트 |
| `npm run typecheck` | 타입 검사 |

### 환경 변수 (`.env`)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | — | Claude API 키. 없으면 AI 버튼이 규칙 기반 제안으로 동작합니다 |

## 사용 흐름

### 1. 레퍼런스 추가 — `레퍼런스 추가`

- 링크를 여러 개 붙여넣으면(줄바꿈으로 구분) 한 번에 가져옵니다. 다른 탭의 이미지를 끌어다 놓거나, 라이브러리 화면에서 `Ctrl+V`로 링크를 붙여넣어도 됩니다.
  - **핀터레스트 핀** (`pinterest.com/pin/…`, `pin.it/…`): 원본 해상도 이미지를 가져옵니다.
  - **핀터레스트 보드/프로필** (`pinterest.com/사용자/보드/`): 공개 보드의 RSS에서 핀 목록을 가져옵니다.
  - **일반 웹페이지**: og:image, 본문 이미지, srcset(가장 큰 해상도), lazy-load 이미지를 후보로 보여줍니다.
  - **이미지 직접 링크**
- 후보 중 원하는 이미지를 고른 뒤 **키워드 태그**, **케이스**, **유형(이미지/로고)**, 메모를 지정해 저장합니다.
- 같은 이미지 주소가 이미 있으면 새로 만들지 않고 태그만 합칩니다.
- `저장 후 AI로 태그·제목 자동 보강`을 켜면 저장한 이미지마다 Claude가 태그와 제목을 제안합니다. 라이브러리에서 이미 쓰는 태그를 재사용하도록 유도합니다.

### 2. 검색·정렬 — `레퍼런스` 탭

- 검색 문법: `조형물 야간조명`(공백 구분), `#네온사인`(태그와 정확히 일치), `"포토 존"`(구문), `-로고`(제외).
- 매칭 방식은 **하나라도**(OR, 많이 맞을수록 위로)와 **모두**(AND) 중에서 고릅니다. 정렬 기준은 관련도, 최신, 오래된 순, 제목, 가로→세로 비율입니다.
- **태그별 그룹** 보기에서 검색 결과가 어떻게 묶이는지 미리 확인할 수 있습니다. 문서를 자동으로 만들 때도 같은 규칙을 씁니다.
- 여러 개를 선택(`Ctrl`/`Shift`+클릭)해 태그 추가·제거, 케이스 지정, 로고 전환, 삭제, 선택 항목으로 문서 만들기를 한 번에 할 수 있습니다.
- 사이드바의 태그 메뉴(⋯)에서 태그 이름을 바꾸거나 다른 태그와 병합할 수 있습니다.

### 3. 케이스 — `케이스` 탭

하나의 사례(경기장, 매장, 브랜드 등)를 묶는 단위입니다. 케이스명, 서브타이틀, 강조 라인(예: `스폰서 : Allianz AG (보험/금융) / 소유: Allianz AG`), 설명, 태그를 관리합니다. `AI로 설명 채우기`로 소속 이미지를 분석해 빈 칸을 채울 수 있습니다. 유형을 '로고'로 지정한 레퍼런스는 케이스 페이지의 **로고 패널**(라벨 칩 + 로고)에 배치됩니다.

### 4. 문서 자동 생성 — `키워드로 문서 만들기`

키워드를 넣으면 오른쪽에 **그룹 미리보기**와 **페이지 미리보기**가 바로 나타납니다.

- **페이지 구성 기준**
  - **케이스별**: 케이스마다 케이스 스터디 페이지를 만들고, 케이스에 속하지 않은 레퍼런스는 태그로 묶습니다.
  - **태그별**: 검색어가 여러 개면 검색어별로 묶습니다. 하나면 결과 안에서 자주 쓰인 다른 태그로 나눕니다. 이미지가 적은 그룹은 매칭된 검색어 그룹이나 `기타`로 합칩니다.
  - **묶지 않음**
- 그룹 이름을 고치거나 체크를 해제해 빼고 만들 수 있습니다.
- 이미지 배치 방식, 페이지당 최대 이미지 수(넘으면 균등 분할: 11장 → 6+5), 페이지 크기(A4 가로·세로, A3, 16:9), 하단 양식, 타이포 프리셋, 표지, 간지를 설정합니다.
- `생성 후 AI로 작성`을 켜면 편집기가 열린 직후 모든 페이지의 빈 칸(타이틀·설명·캡션)을 채웁니다.

| 캔버스 | 선택·이동·크기 조절, 스냅 가이드(여백·중앙·다른 요소), 드래그 영역 선택, 텍스트 더블클릭 편집, 이미지 더블클릭으로 교체 |
| 도구 모음 | 텍스트·사각형·원·선·이미지 추가, 실행 취소/다시 실행, 정렬·간격 균등, 순서(앞/뒤), 복제·삭제, 확대·축소, AI 분석, 웹 뷰어·발표·내보내기 |

**이미지 배치 모드**

| 모드 | 설명 |
| --- | --- |
| 그리드 (N단) | 지정한 열 수로 균등하게 나눕니다. 마지막 줄은 남은 이미지로 가로를 채웁니다 |
| 자유 · 가로 정렬 | 같은 줄 이미지의 높이를 맞추고, 원본 비율을 유지한 채 각 줄이 폭을 꽉 채웁니다 |
| 자유 · 세로 정렬 | 메이슨리 방식입니다. 같은 열 이미지의 폭을 맞추고 각 열이 높이를 꽉 채웁니다 |
| 자유 · 모자이크 | 이미지 비율에 맞춰 영역을 재귀 분할해 크고 작은 칸을 만듭니다(예시 1과 같은 구성). `섞기`로 다른 배열을 고를 수 있습니다 |

자동 레이아웃 이미지를 다른 이미지 위로 끌어다 놓으면 자리가 바뀝니다. 빈 곳에 놓으면 자유 배치로 전환됩니다. 인스펙터에서 다시 포함시킬 수 있습니다.

**단축키**

| 키 | 동작 |
| --- | --- |
| `V` `T` `R` `O` `L` | 선택 / 텍스트 / 사각형 / 원 / 선 도구 |
| `Enter` / 더블클릭 | 텍스트 편집 (`Esc` 또는 `Ctrl+Enter`로 완료) |
| `Ctrl+Z` / `Ctrl+Shift+Z` (`Ctrl+Y`) | 실행 취소 / 다시 실행 |
| `Ctrl+C` `Ctrl+V` `Ctrl+D` | 복사 / 붙여넣기 / 복제 |
| `Ctrl+A` | 페이지 요소 전체 선택 |
| `Delete` | 삭제 |
| 방향키 (`Shift` = 10pt) | 선택 요소 이동. 선택이 없으면 페이지 이동 |
| `Ctrl+]` `Ctrl+[` (+`Shift`) | 앞으로 / 뒤로 (맨 앞 / 맨 뒤) |
| 드래그 중 `Shift` / `Alt` | 한 축으로 고정 / 스냅 끄기 |

모든 좌표는 **pt 단위**이므로 인쇄나 PPTX로 옮겨도 크기가 그대로 유지됩니다. 편집 내용은 자동 저장됩니다.

### 6. 출력

| 방식 | 설명 |
| --- | --- |
| **PDF (인쇄)** | 실제 용지 크기(@page)로 배치한 인쇄 화면이 열립니다. 인쇄 창에서 'PDF로 저장'을 선택하세요(배경 그래픽 켜기) |
| **PowerPoint** | 텍스트는 편집 가능한 텍스트 상자로, 이미지는 크롭·초점·모서리를 반영해 들어갑니다. 발표자 노트도 포함됩니다 |
| **HTML 웹 문서** | 서버 없이 열리는 단일 파일입니다. 스크롤 보기와 발표 모드(`P`)를 지원하고 이미지는 원본 링크를 씁니다 |
| **웹 뷰어 / 발표** | `#/view/문서ID` 주소로 공유합니다. 발표 모드는 전체 화면이며 방향키·클릭으로 넘기고 `N`으로 발표자 노트를 봅니다 |
| **JSON** | 문서 데이터 백업 |

라이브러리 전체(레퍼런스·케이스·문서)는 사이드바의 **백업 내려받기 / 가져오기**로 옮길 수 있습니다.

## AI (Claude)

- `AI 분석`: 현재 페이지의 이미지(최대 12장)와 태그·제목·메모, 케이스 정보, 검색 키워드를 근거로 **타이틀·서브타이틀·강조 라인·설명·섹션 라벨·이미지별 캡션·태그**를 만듭니다. 결과를 확인하고 고친 뒤 원하는 항목만 적용할 수 있고, 추가 요청(예: "더 짧게")을 넣어 다시 생성할 수 있습니다.
- `전체 AI 작성`: 모든 페이지의 **비어 있는 칸만** 채웁니다. `Ctrl+Z` 한 번으로 되돌릴 수 있습니다.
- 응답은 구조화 출력(JSON 스키마)으로 받습니다. 이미지는 서버가 받아서 base64로 전달하므로 핫링크가 막힌 이미지도 분석할 수 있습니다.
- 모델 기본값은 `claude-opus-5`이고 `CLAUDE_MODEL`로 바꿀 수 있습니다. 모델이 요청을 거절할 경우에 대비해 서버 측 폴백(`fallbacks: "default"`)을 켜 두었습니다.
- API 키가 없으면 태그·제목을 조합한 **규칙 기반 제안**으로 동작하고, 화면에 그 사실을 표시합니다.

## 알아둘 점

- 이미지는 **링크로만** 연결합니다. 원본이 삭제되거나 주소가 바뀌면 이미지가 보이지 않습니다. 그럴 때는 레퍼런스 상세에서 주소를 교체하세요. 핫링크가 막힌 이미지는 자동으로 서버 프록시(`/api/proxy`)를 거쳐 표시합니다.
- 핀터레스트는 **공개** 핀·보드만 가져올 수 있습니다. 보드 RSS는 최근 핀 위주로 제공되므로 오래된 핀은 개별 핀 링크로 추가하세요.
- 서버는 기본적으로 `127.0.0.1`에만 열립니다. 스크랩과 프록시는 사설망·로컬 주소를 차단합니다(SSRF 방지).
- 웹폰트(Pretendard, Poppins, Noto Sans KR 등)는 CDN에서 불러옵니다. PPTX를 여는 PC에 해당 폰트가 없으면 대체 폰트로 보입니다.

## 구조

```
shared/types.ts          데이터 모델 (레퍼런스·케이스·문서·페이지·요소, 단위 pt)
server/
  index.ts               Express API + 클라이언트 제공 (dev: Vite 미들웨어)
  scrape.ts              핀터레스트 핀/보드(RSS)·웹페이지 이미지 추출
  net.ts                 안전한 fetch (SSRF 차단, 리다이렉트 검사, 이미지 프록시)
  ai.ts                  Claude 분석 (구조화 출력) + 규칙 기반 대체
  db.ts                  JSON 파일 저장소 (data/db.json)
src/
  layout/engine.ts       레이아웃 엔진 (그리드·가로 정렬·세로 정렬·모자이크)
  layout/templates.ts    페이지 템플릿 (케이스/레퍼런스/표지/간지) + 재배치
```
