# 공식 로그인 버튼 리소스 (선택)

이 폴더에 아래 파일을 넣으면 로그인 화면이 그 파일을 심볼로 씁니다. 없으면 각 사 가이드의 색·형태대로 그린 기본 심볼을 씁니다.

| 파일 이름 | 받는 곳 |
| --- | --- |
| `kakao-symbol.svg` (또는 `.png`) | Kakao Developers → 문서 → 카카오 로그인 → 디자인 가이드 → 리소스 다운로드 (말풍선 심볼) |
| `naver-symbol.svg` (또는 `.png`) | NAVER Developers → 네이버 로그인 → BI 가이드/리소스 다운로드 (N 로고) |

파일을 넣은 뒤 `npm run build` 로 다시 빌드하면 적용됩니다.
